MakePort 0.3.0 позволяет одновременно работать с несколькими проектами по SSH и добавлять пробрасываемые порты прямо в интерфейсе.

### Новое

- Откройте несколько папок на одном или разных серверах. Каждая использует собственный `makeport.toml`, порты, задачи, состояния и журналы.
- Переключение проекта сохраняет работу остальных подключений. Одинаковые make-цели в разных папках запускаются независимо.
- Кнопка **«+ Порт»** добавляет ручной проброс: серверный порт, необязательный локальный порт и описание. В активном проекте он подключается сразу, без остановки задач.
- Ручные порты сохраняются локально для выбранной папки, дополняют файл проекта и отмечены «вручную». Кнопка **×** закрывает только этот туннель; **«Повторить»** восстанавливает его после ошибки.
- При конфликте локальных портов приложение сообщает, какой проект использует номер. Выберите другой локальный номер.
- Отключение затрагивает только выбранный проект. Закрытие приложения останавливает задачи и туннели во всех проектах.
- Состояние неизвестного запуска хранится отдельно для каждого проекта и не мешает переключаться к другим.

### Совместимость и загрузка

Профили версии 0.2.0 открываются автоматически. Ручные изменения сохраняются в локальном `config.toml`; файлы на сервере не изменяются.

Доступны отдельные исполняемые файлы для Windows x64, Linux x64, macOS Apple Silicon и macOS Intel, без ZIP. Проверка загрузки — по `SHA256SUMS`. На macOS и Linux выполните `chmod +x <имя-файла>` перед запуском. macOS-бинарники имеют локальную подпись без Developer ID и нотарификации Apple.

Состояние «Проброшен» подтверждает SSH-туннель, а не готовность приложения за ним. Используются ваши SSH-настройки, ключи и агент; интерактивный ввод пароля не поддерживается.
