MakePort 0.4.0 — один локальный конфиг, массовый проброс портов и простой интерфейс.

### Подключение в два поля

Укажите сервер и порты, затем нажмите **«Подключить»**. Название подключения, папка и необязательные задачи Make находятся в **«Дополнительно»**.

- Все подключения, порты и задачи хранятся в одном локальном `config.toml`.
- До 256 портов на подключение через один SSH-процесс, с одной аутентификацией и общим восстановлением связи.
- Вводите отдельные порты, списки и диапазоны: `3000, 15432:5432, 8000-8010`. Для сдвига диапазона: `18000-18010:8000-8010`.
- Новые порты добавляются прямо над списком. Пакет добавляется целиком за одно переподключение; дубликаты и некорректные номера отклоняют всё изменение настроек.
- Общий статус соединения и компактные строки портов. Задачи Make свёрнуты; неподтверждённые задачи раскрываются автоматически.
- Работа с конфигом, журнал, трей и выход собраны в **«Настройки»**.
- Для проброса не нужны папка проекта и Make на сервере. Они требуются только для запуска задач Make.
- Сворачивание и закрытие окна сохраняют работу в трее, если системный трей доступен. Для завершения выберите **«Настройки → Выйти из MakePort»** или пункт меню трея.

### Работа с портами

Добавление и удаление портов пересоздаёт общий туннель этого подключения: текущие TCP-соединения через него прервутся. Запущенные задачи Make продолжают работать в отдельных SSH-сеансах. При ошибке привязки одного порта весь набор получает ошибку вместо частичного успеха.

### Платформы

Релизный workflow собирает отдельные исполняемые файлы для Windows x64, Linux x64, macOS Apple Silicon и macOS Intel и создаёт общий `SHA256SUMS`. На Linux и macOS перед запуском выполните `chmod +x <имя-файла>`. macOS-бинарники имеют локальную подпись без Developer ID и нотарификации Apple.

Используются системный OpenSSH, существующие ключи и SSH-агент. Для удалённого подключения нужны POSIX `sh` и `cat`; интерактивный ввод пароля не поддерживается. Готовность туннеля не означает готовность сервиса за ним.
