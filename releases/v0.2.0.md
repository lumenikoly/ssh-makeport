MakePort 0.2.0 упрощает работу с проектом на сервере: укажите SSH-адрес и папку, затем запускайте действия и открывайте проброшенные порты.

### Что изменилось

- Компактный интерфейс с мягким светлым оформлением, карточками и цветными состояниями. Журналы открываются отдельно.
- Открытие папки по SSH через одну форму: адрес и путь. Используются локальные SSH-настройки, ключи и SSH-агент.
- Файл `makeport.toml` в папке проекта на сервере задаёт порты и make-действия с понятными описаниями. `local` необязателен и по умолчанию совпадает с `remote`.
- Файл проверяется до создания туннелей. Ошибки конфигурации блокируют новое подключение, сохраняя уже работающее при обновлении.
- Перечитывание описаний сохраняет состояние активных задач. Изменения портов применяются после переподключения.
- Для проектов без конфигурации сохранено обнаружение действий из Makefile.
- Кнопки поддерживают клавиатуру, видимый фокус и доступность. Отключённая кнопка не выполняет действие по Enter.

### Загрузка

Выберите исполняемый файл для своей системы: Windows x64, Linux x64, macOS Apple Silicon или macOS Intel. ZIP-архивы не нужны. Контрольные суммы — в `SHA256SUMS`.

На macOS и Linux после загрузки выполните `chmod +x <имя-файла>` и запустите файл. macOS-бинарники имеют локальную подпись, без Developer ID и нотарификации Apple.

Пример конфигурации: [makeport.example.toml](https://github.com/lumenikoly/ssh-makeport/blob/v0.2.0/makeport.example.toml). Сохраните его как `makeport.toml` в удалённой папке проекта.

Состояние «Проброшен» подтверждает SSH-туннель, а не готовность приложения за ним. Доступ по SSH должен быть заранее настроен; интерактивный ввод пароля не поддерживается.
