# Проверка без Node.js

Скопируйте эту папку на SSH-машину. Нужны Make и Python 3.
В MakePort создайте проект с путём к этой папке, портом `5173` и задачами `dev, test, fail`.
Нажмите «Подключить», запустите `dev` и нажмите «В браузер».
Задача `test` завершится успешно, `fail` проверит отображение ненулевого кода.
У задачи `dev` проверьте «Стоп»: после подтверждения завершения сайт должен
перестать отвечать. Затем отключите проект: локальный порт освободится.
