# История изменений

## 0.4.0 — 7 ноября 2026

- Автоматический поиск подключений в пользовательском и системном SSH-конфигах, включая Include; выбор через «Из SSH» в поле сервера.

- Исправлено подключение из Windows при CRLF в служебных shell-скриптах; ошибки скрипта диагностируются отдельно от сетевых.

- Ускорение сборки: 16 блоков генерации кода при сохранении ThinLTO; Rust закреплён на 1.98.1.
- Release повторно использует готовую Linux-сборку того же коммита; общий кэш зависимостей, отмена устаревших Build и облегчённая передача артефактов.

- GitHub Actions выполняет сборку и выпуск; тесты и Clippy запускаются локально.

- Упрощённый UX: два основных поля подключения — сервер и порты, остальное в «Дополнительно».
- Добавление одного или нескольких портов прямо в списке, без отдельной формы и лишнего переподключения на каждый порт.
- Компактные строки портов и один общий статус соединения; задачи Make свёрнуты, технические действия собраны в «Настройки».

- Один локальный `config.toml` для всех подключений, портов и необязательных задач Make.
- Все порты подключения передаются одному SSH-процессу; до 256 портов, поддержаны диапазоны в форме.
- Изменение списка портов пересоздаёт общий туннель, сохраняя работающие задачи Make.
- Проброс не требует папки проекта и Make.
- Перечитывание общего конфига после отключения соединений с сохранением неподтверждённых задач.

- Иконка приложения, окна и Windows EXE; ресурсы для macOS и Linux.
- Сворачивание и закрытие окна в трей без остановки подключений и задач.
- Меню трея с возвратом окна, количеством подключений и задач и полным завершением.
- На Linux окно остаётся доступным при отсутствии или исчезновении системного трея.
- Новый интерфейс: список проектов слева, компактные строки портов и задач, единые иконки и зелёные акценты.
- Копирование адресов портов, всего журнала и выделенного текста.
- Русское меню редактирования, поддержка Ctrl+C/V/X/A в русской раскладке, Ctrl+Insert и Shift+Insert.
- Автофокус форм, Enter для перехода к следующему полю, Escape для закрытия диалога.

## 0.3.0

- Несколько одновременно подключённых проектов и папок, каждый со своим makeport.toml.
- Переключение проектов без закрытия туннелей и остановки фоновых задач.
- Отдельные состояния, журналы, восстановление связи и неподтверждённые запуски для каждого проекта.
- Добавление портов в UI: серверный и локальный номер, описание, сохранение для конкретной папки.
- Добавление, удаление и повторное подключение ручного туннеля без прерывания make-задач.
- Диагностика конфликтов локальных портов между проектами.
- Закрытие приложения корректно останавливает работу во всех проектах, включая скрытые.
- Совместимость с профилями 0.2.0; добавлен тест одновременных проектов для Windows, Linux и macOS без настоящего SSH-сервера.

- CI сокращён до 12 основных проверок на Linux; тесты не повторяются на каждой релизной платформе.

## 0.2.0

- Конфигурация `makeport.toml` в удалённой папке: порты и make-действия с описаниями.
- Чтение конфигурации до проброса портов, проверка содержимого и обновление без потери состояний задач.
- Простая форма открытия папки по SSH и компактный основной экран.
- Светлое оформление с сиреневыми акцентами, карточками и цветными статусами.
- Управление кнопками с клавиатуры и поддержка доступности.
- Подготовленные описания релизов и синхронизация версии macOS-пакета с Cargo.toml.

## 0.1.0

- Подключение через системный OpenSSH, локальные профили и проброс портов.
- Поиск make-целей, запуск, вывод и остановка задач.
- Сохранение неподтверждённых запусков и восстановление соединения.
- Ручной выпуск Windows, Linux и macOS-бинарников по тегу с SHA256SUMS.
